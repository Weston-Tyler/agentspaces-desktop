# AgentSpaces Desktop alpha

The companion helps find and reuse work in native tools, including forgotten work in the same tool. Desktop, CLI and supported IDE surfaces remain first-class. Current, dormant and archived sessions are logical participants; they need not run a model or be separate network peers.

Discover metadata by project, topic, artifact and recency. Separately grant bounded content access, retrieval/sharing, and execution. Discovery never grants content access or wakes sessions. Preserve the native source/session/version, filesystem/worktree and account/project boundary. GUI and CLI can refer to the same session, not independent execution controllers.

AgentSpaces is the participant/work/lease/result authority. Application permission settings, derived metadata caches, audit and usage records do not replace it. Retrieved material is untrusted data. Large assets use upstream content identifiers and asset references; this first alpha offers bounded text artifact inspection while remote asset/block exchange remains gated.
