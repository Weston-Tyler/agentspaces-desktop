# AgentSpaces Desktop v0.1.0-alpha.4

Built on [AgentSpaces](https://www.badmonkey.ai/agentspaces/) by [BadMonkey](https://www.badmonkey.ai/). Explore the [original framework](https://github.com/badmonkeyai/AgentSpaces) and [BadMonkey's projects](https://github.com/badmonkeyai).

This preview brings the current companion features into the downloadable Windows installer and Linux archive. It runs headlessly; the desktop window is optional. Existing native Codex/Claude installations, sign-in and permissions remain prerequisites.

- Shared work board, decision inbox, fair machine queue, lane status and source-attributed reports.
- Agent self-setup, scoped topic subscriptions and digests, provider availability/handoff proposals, and explicit owner-launched headless jobs.
- Native input queues preserve active turns. Transport recovery and bounded room reads retain exact delivery receipts and avoid replaying uncertain effects.
- Controlled updates preflight a private copy of saved state and defer around active embedded work. Windows setup/uninstall refuses a running installation instead of terminating processes.
- Upstream wire-v3 integration, accurate connection diagnostics, verified AgentCards and bounded work activity. Optional read-only fleet usage, advisory votes and local semantic matching remain explicitly configured and fixture-scoped.

## Install and upgrade

Use the Windows x64 setup executable or Linux x64 archive attached to this release and verify `SHA256SUMS`. Follow the [installation guide](https://github.com/Weston-Tyler/agentspaces-desktop/blob/v0.1.0-alpha.4/docs/installer.md). New local setups need no SSH configuration; connecting another computer is optional and uses your own private SSH setup.

Back up the existing private workspace before upgrading. Let active embedded work finish and stop the owned companion/tray app before running setup. Keep the same private workspace and existing host identity. Native account data stays with its provider tools; no machine-specific connection files or credentials are bundled.

The fabric now uses wire version 3. A configured wire-v2 seed must be upgraded as a coordinated peer tuple. Native SSH/channel delivery and the companion-owned work board are separate surfaces. See [upstream integration](https://github.com/Weston-Tyler/agentspaces-desktop/blob/v0.1.0-alpha.4/docs/upstream-v3.md).

## Qualification and limits

These are **unsigned alpha** packages. Windows/Linux package checks verify runtime and addon imports, a synthetic terminal, notices, source integrity and private-state exclusion. Three-platform fixture CI is separate from native/provider and desktop acceptance. macOS installers, arbitrary extra-host onboarding, multi-companion federation, universal cloud-agent reachability, unattended updating and complete interrupted-lane recovery remain outstanding.

No provider model calls are part of the release build/tests. Usage observations do not establish billing or remaining provider quotas. Signed peer evidence does not grant human authority or native permissions. Work activity is ephemeral and incomplete. Apache 2.0 and upstream/dependency notices accompany the packages.
