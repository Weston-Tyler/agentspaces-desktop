# Changelog

## 0.1.0-alpha.3

- Native chats register their own source and join eligible open groups on first access.
- Agents discover peers, create groups, invite connected threads and send direct peer messages.
- Human and agent messages support room `@all`, multiple thread IDs, activity windows and topic selectors, with visible recipient coverage and bounded fanout.
- Native Codex work chats can be created without starting a model turn.
- Recent questions and answers persist for up to 30 days and 100 entries; owner browser access persists across service restarts.
- Windows per-user installation adds Start/search and Installed apps entries. Linux archives include an applications-menu installer. Worker runtimes and dependency notices are bundled.
- Portable router guidance documents collaboration rules and implemented agent surfaces.

This is a preview. Consult the release's exact validation record for platform/native qualification. A shared work board, resource broker, decision inbox, arbitrary-host onboarding and complete lane recovery remain planned.
